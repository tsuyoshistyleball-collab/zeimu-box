# 税務ボックス

銀行明細・クレジットカード明細を **Googleドライブの決まったフォルダに自動で整理して保存** し、集計できるアプリです。
スマホのホーム画面にインストールできる **PWA**（ウェブアプリ）として作っています。

## 画面は3つだけ

| 画面 | やること |
|---|---|
| ⬆️ 保存 | 口座を選ぶ → 明細ファイルを選ぶ → 「保存する」。`口座 / 第N期 / R8/8.csv` に自動で入ります |
| ✅ 確認 | 期を選んで「表示」。未保存の月が「−」で分かり、取引の検索・CSV書き出しもできます |
| ⚙️ 設定 | 口座・カードの追加と解約、Googleの設定 |

- 口座・カード ＝ ドライブの「仕事で使用」フォルダの中のフォルダです。ドライブで直接作ってもOK。
- 売上振込（Amazon・ヤフー・メルカリShops・auPAYマーケット など）＝「売上振込Amazon、ヤフー、メルカリ、au」フォルダの中のフォルダです。
  - ファイル名は元の名前のまま保存します（保存前に編集できます）。
  - 中に「第N期」フォルダがある口座はそこへ、ない口座（Amazon・ヤフー）はフォルダに直接保存します。
  - auPAYマーケットのように中が分かれているものは「auPAYマーケット / GMO-PG振込明細書」のように1つずつ選べます。
- アプリはドライブのフォルダ名を変えません。解約は見えない印を付けるだけです（明細もそのまま）。

## ファイル構成（学習用メモ）

```
index.html            画面の骨組み
style.css             見た目
config.js             設定（保存先フォルダ・決算月など）← まずここを見る
version.js            アプリのバージョンと更新履歴（更新のたびに数字を上げる）
js/app.js             画面の操作をまとめた本体
js/drive.js           Googleログインとドライブ操作
js/parsers.js         CSVの読み取り（文字コード判定・列の自動判定）
js/fiscal.js          第N期・和暦ファイル名の計算
manifest.webmanifest  インストール用の情報（名前・アイコン）
sw.js                 サービスワーカー（オフライン表示・共有の受け取り）
```

## 使い始めるまでの手順

### 1. GitHub Pages で公開する
1. GitHub にこのリポジトリをアップロード
2. リポジトリの **Settings → Pages** → Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります

### 2. Googleの設定（クライアントIDを作る）
アプリがあなたのドライブにファイルを保存するための「鍵」を作ります。最初の1回だけです。

1. https://console.cloud.google.com/ を開き、新しいプロジェクトを作成（名前は「税務ボックス」など）
2. **APIとサービス → ライブラリ** で「Google Drive API」を検索して **有効にする**
3. **APIとサービス → OAuth同意画面**（Google Auth Platform）
   - ユーザーの種類：**外部** / アプリ名・メールを入力
   - **対象ユーザー（テストユーザー）に自分のGmailアドレスを追加**
   - ログインをずっと維持したい場合は、「対象」画面で公開ステータスを **「本番環境」** にする
     （「テスト」のままだと、1週間ごとに許可し直しを求められることがあります）
4. **APIとサービス → 認証情報 → 認証情報を作成 → OAuth クライアントID**
   - 種類：**ウェブアプリケーション**
   - 承認済みの JavaScript 生成元：`https://<ユーザー名>.github.io`（パソコンで試すなら `http://localhost:8000` も）
5. 表示された「クライアントID」（`xxxx.apps.googleusercontent.com`）をコピー
6. アプリの **⚙️設定** に貼り付けて保存 → 右上の **ログイン**

### ログインについて
- 一度ログインすれば、「ログアウト」を押すまでログインしたままです（更新・再起動しても切れません）。
- Googleの決まりで通行証は約1時間で切れますが、次にボタンを押したとき自動で取り直します（一瞬ポップアップが開いて閉じます）。
- iPhoneは、Safariのタブではなく **ホーム画面に追加したアプリ** で使ってください。Safariは、しばらく開かないサイトの保存データを消すことがあります。

> 「このアプリはGoogleで確認されていません」と出たら「詳細」→「（安全でないページ）に移動」で進めます。自分で作ったアプリなので問題ありません。

### 3. スマホにインストール
- **iPhone**：Safariで開く → 共有ボタン → 「ホーム画面に追加」
- **Android**：Chromeで開く → メニュー → 「アプリをインストール」

## パソコンで動かして試す
```bash
python3 -m http.server 8000
```
ブラウザで http://localhost:8000 を開きます。
